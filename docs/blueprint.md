# **App Name**: ChapterLink

## Core Features:

- User Authentication: Secure authentication system for admin access to manage the book catalog.
- Book Catalog: Browse books by categories, with detailed book information.
- Advanced Search & Filtering: Enable users to search books by title, author, and filter by genre, price, etc.
- Shopping Cart: Add books to a shopping cart with localStorage persistence.
- WhatsApp Checkout: Integrate WhatsApp for a streamlined checkout experience.
- Admin Dashboard (DecapCMS): Utilize DecapCMS to manage the book inventory.
- SEO Optimization: Optimize website content to improve visibility to search engines, use a tool to check optimization opportunities

## Style Guidelines:

- Primary color: Dark purple (#646cff) for a modern look, matching provided --primary-color.
- Background color: Light gray (#f0f2f5), a desaturated version of the primary color for a clean backdrop.
- Accent color: Slightly darker purple (#535bf2) for interactive elements and highlights, matching provided --secondary-color.
- Font: 'Inter' sans-serif for body text and headings for modern feel. Note: currently only Google Fonts are supported.
- Responsive design for all devices, using breakpoints sm: 640px, md: 768px, lg: 1024px, xl: 1280px, to ensure a seamless experience across different screen sizes.
- Consistent use of minimalist icons for categories and cart actions.
- Subtle transition effects for hover states, cart updates, and page transitions to improve user experience.
